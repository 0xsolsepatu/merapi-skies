**Merapi Skies — Island Bush Pilot**: an original 3D flight game that plays offline in a desktop browser. Fly a low-poly STOL bush plane around Pulau Merapi, a volcanic island with three airstrips, coral coasts and crater villages. Four missions (Ring Run, Island Hop, Supply Drop, Free Flight), a real flight model (stall, flaps, engine overheat, fuel, damage, smooth-landing scoring), a lit instrument panel (airspeed, altitude, heading, artificial horizon, fuel/heat/damage) and synthesised WebAudio engine and wind sounds. No network, no copied art or names — every texture, model and sound is generated by the game's own code.

## Play it

```sh
node serve.ts   # then open http://localhost:8080
```

W/S throttle, arrow keys pitch and bank, mouse steers, wheel throttles, F flaps, B airbrake, Space drops a crate, C switches chase/cockpit camera, P pauses, R restarts, M mutes.

## Hand it in

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
